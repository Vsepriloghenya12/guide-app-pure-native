# Удаление старых изображений главного экрана

Проверено: старые изображения больше не находятся в проекте и не подключаются через `require(...)` или URL-ссылки:

- `welcome-background.png`
- `home-header-mesto.png`
- `home-hero-background.png`
- `home-hero-logo-custom.png`
- `logo-placeholder.svg`

Дополнительно welcome-экран мобильного приложения теперь использует актуальный логотип из `mobile/assets/icon.png`, а не текстовую заглушку `место`.

Оставлены только нужные изображения:

- новый логотип/иконка приложения;
- splash;
- иконки категорий;
- знак качества места.
