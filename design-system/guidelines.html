Как проектировать для этого приложения

Приложение — React Native (Expo), стили — RN StyleSheet. Всё, что нарисовано здесь, будет переноситься в нативные стили, поэтому есть ограничения.

Можно свободно ✓

  • Цвета, размеры, радиусы, отступы, тени (iOS shadow + Android elevation)
  • Плоские заливки, полупрозрачность (rgba)
  • Иконки — любые SVG-контуры (в приложении есть react-native-svg)
  • Простые анимации: fade, translate, scale (Animated API)
  • Компоновка flexbox: row/column, gap, align, justify

Ограничения ✗

  • Нет CSS-градиентов (linear-gradient) — только сплошные цвета, если не добавим expo-linear-gradient
  • Нет backdrop-blur — вместо блюра полупрозрачная заливка
  • Анимации внутри маркеров карты не работают (маркеры растеризуются) — пульс точки «вы здесь» имитируется статичным ореолом
  • Карта — настоящий Google Maps (react-native-maps): кастомизировать можно маркеры, линии, оверлеи поверх карты; сами тайлы — только через map style JSON
  • Шрифт — системный (SF Pro / Roboto). Кастомные шрифты возможны, но это отдельное решение

Структура экранов

  • Карточка места: шапка «Твой гид» → фото с чипом категории → заголовок+рейтинг+бейджи → описание → пилюли → инфоблоки (адрес/часы/телефон) → карта (340px, во всю ширину, всплывающая CTA) → «Как добраться»
  • Полноэкранный маршрут: карта на весь экран, ✕ слева, компас/локатор/зум справа, нижняя панель: ручка → переключатель транспорта (4 режима) → сводка → шаги → «В путь»+поделиться
  • Другие экраны: главная, категории, «Карта» (все места), маршруты города, избранное, профиль

Как передавать дизайн в код

Готовый экран/компонент из Claude Design отдайте в Claude Code (файлом или ссылкой на артефакт) с фразой «примени этот визуал». Claude Code перенесёт в React Native, прогонит ревью и соберёт APK. Компоненты из этой дизайн-системы соответствуют реальным стилям в mobile/App.tsx — их имена указаны в карточках (например detailTitle, mapFullscreenCard).
