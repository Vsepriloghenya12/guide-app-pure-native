# Mobile fixes v9

Исправлено:

- Карточка места защищена от падений, если CMS отдаёт строки вместо массивов для `imageGallery`, `tags`, `extra`, `services`.
- Карточки мест в категориях получили увеличенное фото и ограничение текста внутри общей ширины строки.
- Добавлена нативная карта `react-native-maps`:
  - экран «Карта» показывает все места с координатами;
  - карточка места показывает собственную точку;
  - маршрут показывает точки и линию маршрута внутри приложения.
- «Аренда» на доске объявлений переименована в «Разное».
- Убран блок «Пока нет объявлений».
- Категория «Маршруты» оставлена отдельной от «Готовых программ»: список маршрутов → подробное описание → карта маршрута.

Важно для APK:

- В `mobile/.env` нужно заменить `EXPO_PUBLIC_API_BASE_URL=https://your-app.up.railway.app` на реальный Railway URL.
- Для карты в standalone APK нужен `EXPO_PUBLIC_GOOGLE_MAPS_API_KEY`.
