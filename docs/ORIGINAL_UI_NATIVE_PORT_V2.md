# Original UI native port v2

В этой версии доработаны элементы, которые визуально отличались от исходного web-приложения:

- главный баннер на домашнем экране с боковыми peek-карточками;
- блок готовых программ с белой кнопкой действия;
- нижняя навигация в стиле оригинального приложения;
- страницы категорий без лишней web-заглушки/header;
- верхняя строка категории с кнопкой назад, быстрыми фильтрами и кнопкой фильтра;
- компактные карточки мест в стиле исходного списка ресторанов.

Проект остаётся чистым Expo/React Native приложением без Capacitor/WebView.
