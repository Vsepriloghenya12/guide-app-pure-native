# V19 banner, detail, tips and auth fixes

Что изменено:

- Баннеры остаются кликабельными и листаются по кругу.
- Убран отдельный тёмный прямоугольник под текстом баннера.
- Центральный баннер получил лёгкое затемнение всей картинки, а текст читается за счёт тени.
- На главной показываются только 3 совета.
- Заголовок «Советы» выровнен по центру.
- Кнопка «Все» открывает отдельный экран со всеми советами.
- Карточка места переделана без отдельных карточных обёрток: сначала вся информация, ниже карта.
- В карточку места возвращена встроенная карта через `GuideMap`.
- Если пользователь уже авторизован, кнопка профиля показывает профиль и кнопку выхода, а не повторный вход.
- Telegram login теперь использует прямой `oauth.telegram.org/auth` при наличии bot token и возвращает пользователя в приложение через `danangguide://auth`.

Важно:

- Для рабочей встроенной карты в APK нужен реальный `EXPO_PUBLIC_GOOGLE_MAPS_API_KEY`, добавленный до `prebuild`/сборки.
- Для Telegram login на Railway должны быть `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME`, `PUBLIC_APP_URL`, `AUTH_SESSION_SECRET`.
- После изменения app.config.js или env для карты нужно заново выполнить prebuild/сборку APK.
