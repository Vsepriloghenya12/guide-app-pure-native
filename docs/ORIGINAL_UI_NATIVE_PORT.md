# Original UI native port

Эта версия возвращает внешний вид главной страницы ближе к исходному приложению:

- верхний hero с изображением Дананга;
- логотип «Твой гид»;
- карточка-подборка с боковыми peek-баннерами;
- сетка рубрик 4 колонки с оригинальными иконками;
- блок «Готовые программы»;
- нижняя навигация в стиле исходного приложения.

Это не WebView и не Capacitor: интерфейс собран на React Native/Expo. В проекте нет отдельного browser UI.
