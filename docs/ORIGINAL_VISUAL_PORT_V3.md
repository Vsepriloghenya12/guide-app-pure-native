# Original visual port v3

Эта версия усиливает перенос исходного web-визуала в native/Expo:

- уменьшена высота hero и поднят контент как в исходной главной;
- баннер на главной сделан уже, с боковыми превью и тёмным overlay;
- сетка категорий сжата под оригинальную мобильную сетку 4 колонки;
- карточки категорий/ресторанов переписаны под исходный listing layout: фото слева, название на фото, факты справа;
- нижнее меню сделано белым плавающим pill с активной синей иконкой;
- всё остаётся React Native/Expo без Capacitor/WebView.

Полностью 1:1 перенос требует дальнейшего ручного переноса каждого web-компонента в RN-компонент.
