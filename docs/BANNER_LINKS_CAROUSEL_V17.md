# v17 — баннеры главной

Что изменено:

- Баннеры на главной стали кликабельными.
- Владелец может указать ссылку в CMS в поле «Ссылка перехода при нажатии».
- Поддерживаются внешние ссылки `https://...`, а также внутренние пути `/programs`, `/routes`, `/section/<slug>`, `/place/<slug>`.
- Убран общий тёмный слой поверх баннера. Изображение теперь показывается без затемнения.
- Затемняется только плашка с текстом, чтобы заголовок и описание не сливались с картинкой.
- Карусель баннеров листается по кругу: после последнего баннера снова идёт первый.

После обновления нужно задеплоить backend на Railway и пересобрать APK, потому что изменён mobile-код.
