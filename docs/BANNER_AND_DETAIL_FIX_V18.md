# V18 — баннеры и карточка места

Изменения:

- Главный баннер больше не использует дергающийся автоскролл/FlatList-дубли.
- Карусель баннеров работает по кругу: свайп влево/вправо, боковые preview-карточки и точки.
- Баннеры остаются ссылками через поле `linkPath` / «Ссылка перехода при нажатии» в CMS.
- В карточке места встроенная карта отключена и заменена безопасной кнопкой «Открыть на карте», чтобы Android не закрывал приложение при проблемах Google Maps SDK/API key.
- Версия mobile повышена до 1.0.7.

Важно: после правок нужно собрать и установить новый APK. Если установлено приложение из старой папки или старый APK, изменения баннеров не появятся.
