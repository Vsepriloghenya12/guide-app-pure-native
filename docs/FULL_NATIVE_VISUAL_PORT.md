# Full native visual port

Эта версия продолжает перенос исходного web-визуала в чистый Expo/React Native без WebView/Capacitor.

Перенесено ближе к исходнику:

- верхний home hero с исходными изображениями;
- центральный баннер с боковыми preview-карточками;
- сетка категорий 4 колонки с исходными иконками;
- блок готовых программ;
- нижняя навигация в стиле исходного приложения;
- страницы категорий: верхняя панель назад, быстрые фильтры, кнопка фильтра, карточки мест;
- bottom-sheet фильтров;
- экраны поиска, избранного, карты, контактов и карточки места приведены к единой визуальной системе исходного приложения.

Запуск:

1. npm install
2. npm run mobile:start -- --clear
3. заново отсканировать QR в Expo Go

Если на телефоне визуал не меняется, значит запущена старая папка или кэш Expo Go. Нужно удалить старую папку, распаковать архив в новую папку и запустить с --clear.
